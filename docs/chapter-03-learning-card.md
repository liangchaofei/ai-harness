# 03 复习卡：执行与反馈

阶段一：工具请求→本地执行→关联结果→下一次模型输入。正文与候选已提供，不等于学习者已掌握。

## 需要能自行重建的关系

- ToolDefinition描述能力；ExecutableTool增加本地execute。模型只看到说明，不取得函数。
- JSON.parse只解析JSON，具体工具继续检查参数和允许清单。
- Runtime根据name找本地工具，等待文本，复制原call.id为toolCallId。
- 应用持有messages；push(first)保存整条请求一次，push(...results)保存各项结果；complete/executeTools的return不自动保存。
- 单工具时第二次输入记录3条，含system的HTTP消息4条，保存second后内存记录4条。
- 成功工具、正常停止、任务回答正确分别核对；已知失败作为反馈，未知异常停止后续。
