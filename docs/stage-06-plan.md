# 第六阶段：扩展、安全与人工介入

| 单元 | 能力 | 验收 |
|---|---|---|
| 31 工具执行权限 | CLI 选择只读模式，工具执行入口落实 | 同一批次读取成功，修改和验收被拒，副本无变化 |
| 32 人工逐次批准 | 修改和验收分别等待终端答复 | 批准只作用于当前执行，拒绝写回工具反馈 |

| 35 MCP 外部工具 | 通过 stdio 发现和调用固定发票规则服务 | 初始化、失败重试和连接释放可观察，Runtime 无改动 |
| 36 验收进程执行隔离 | macOS 任务可选择限制验收写入及网络，并绑定检查点 | 直接与隔离运行对照，保留业务验收，拒绝策略错配 |
