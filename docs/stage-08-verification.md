# 第八阶段验收与主线结课记录

八阶段主线教学内容截至第 49 篇。第八阶段从可安装的公开包开始，最后把同一任务运行器接入 CLI、独立宿主和 Electron。这里记录项目实现与作者验证，学习者独立完成度单独记录。

| 能力 | 实际证据 |
| --- | --- |
| 公开包与独立消费 | 在仓库外安装四份本地包，严格编译并对照接受与缺验收。[第 44 篇验证](chapter-44-verification.md) |
| 共用运行、取消、审阅 | 修改后仍可取消和审阅，拒绝并发操作及旧运行结果。[第 45 篇验证](chapter-45-verification.md) |
| 原生窗口及进程边界 | 验证固定 preload API、主进程运行、取消与退出。[第 46 篇验证](chapter-46-verification.md) |
| 任务与模型接入 | 验证两个实际任务、主进程配置、模拟流式服务和真实验收。[第 47 篇验证](chapter-47-verification.md) |
| 历史与证据审阅 | 独立进程重启后读取改动前后、验收与取消记录。[第 48 篇验证](chapter-48-verification.md) |
| 执行前人工批准 | 验证逐项身份、拒绝、取消、关窗与重开，以及终端原路径兼容。[第 49 篇验证](chapter-49-verification.md) |

收尾对照以路径任务验证两种宿主。CLI 和桌面各自使用同一个 Harness 执行前包装器，对实际修改和验收分别询问。终端批准后完成 TypeScript 路径任务的实际验收，桌面批准后完成内置 JavaScript 路径任务的实际验收。两者使用各自可信的材料及脚本。

## 证据范围

课程交付包含本地安装包、CLI、原生桌面入口、示例、可重复验收与课程文档。最终联调以固定模型和模拟协议响应证明接线与业务执行。付费服务长期表现、非受信代码的生产级隔离、安装器分发和公开包发布需另外验证。Pi 专题源码研读作为独立学习安排。第 49 篇仍由学习者自行提交。
