# 16学习卡

问题：任务执行到哪一步，实际失败后需要怎样调整？

模型update_plan→Runtime原执行门禁→计划解析/序号核对→私有current保存→工具返回快照→循环保存反馈→下一轮。应用tool_end后另用read副本显示，不拥有历史追加权。

计划步骤是声明，不是执行节点；completed不是验收通过；计划revision不是源码哈希。拒绝旧序号不改current，完成项可因新发现重新打开。状态只在内存，每次任务新建。

同材料固定直接4/5、计划5/8，实际两次修改和检查相同，说明额外成本；不证明真实质量提升。默认关闭，按任务选择。全勾完无修改/验收仍拒绝。真实独立使用/迁移/延迟复用待取证。

后续CLI复用原循环与控制，不把固定模型装置当应用能力；更完整Harness/持久化/编排按阶段继续。
