# 19 完整运行记录与本轮模型输入：设计与实施计划

所属第四阶段；JD能力为上下文组织、输入与执行证据分离、可复用运行框架。学习起点为干净的agent/chapter-18-stage-delivery，实际CLI8模型/12工具/60秒、输出1024，18真实机制已运行；学习者掌握仍未知。

能力契约：每次模型调用前，Runtime以独立消息副本调用应用可选prepareMessages，默认保留全量；返回的消息仅组成本轮Context，原运行记录只追加实际模型响应与工具结果。应用能够注入本轮提示并观察条数，不污染报告。准备失败在模型调用前停止、返回input阶段受控失败，不消耗模型调用额度；原取消/时限覆盖等待且阻止迟到输入启动模型。

选择：消息准备回调比重写整个Context更符合当前需求，不允许回调直接改系统要求或工具能力；不将选择策略塞进模型提供商编码。暂不实现裁剪、摘要、工具消息分组、token估算、落盘/恢复或新CLI开关。消息对象与assistant.toolCalls复制，保护当前文本消息结构；不宣称隔离不可信插件或语义验证。回调是可信应用代码，必须保留本轮所需信息与工具关系。

Pi设计前核对固定8efd314fa3d3232ce197d8d7a6a5660530b9d83e中streamAssistantResponse和AgentLoopConfig.transformContext/convertToLlm；本项目只有统一Message，无自定义AgentMessage转换层，采用独立副本与受控准备失败，不照搬Pi要求回调不抛错的契约。
