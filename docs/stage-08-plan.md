# 第八阶段：框架收敛与桌面应用

| 单元 | 能力 | 验收 |
| --- | --- | --- |
| 44 可安装 Harness 入口 | 在公开包入口复用运行、工作区会话和交付判断 | 独立 npm 项目使用本地打包产物编译并实测验收，CLI 回归通过 |
| 45 共享任务运行器 | 在同一会话上运行、观察、取消与审阅 | CLI 与仓库外宿主复用，验证正常交付、取消和旧结果拒绝 |
| 46 桌面宿主与 IPC | Electron 渲染器通过固定操作启动和取消任务 | 实际窗口显示进度和验收，验证取消和关窗退出 |
| 后续：桌面任务与权限交互 | 收敛任务选择、模型配置、会话与人工批准 | 主进程持有凭据和执行，渲染器只展示有限状态 |

阶段目标是在现有工程中收敛可消费接口，再用桌面应用验证边界。包分发先用本地构建产物，公开发布另行处理。
