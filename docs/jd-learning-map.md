# 岗位能力来源与新版课程覆盖

来源：学习者提供的三张岗位截图可见职责，分别涉及Agent Harness专家/高级、Agent harness研发与企业级Agent Harness研发。只记录可见要求，不补全被折叠文字。技术路线使用TypeScript，不设Python前置。

| 可见技术要求 | 新版课程建设阶段 |
|---|---|
| Agent循环、ReAct、任务理解、规划、执行和反馈 | 一至三，后续任务持续复用 |
| Runtime、状态持久化、断点恢复、可靠执行 | 二、五 |
| Context/Memory、输入组装、压缩与关键信息保持 | 四 |
| Tool/Skill、参数验证、权限、安全、沙箱 | 二、三、六 |
| 人工介入与多方协作 | 六，八接入界面 |
| Tracing、失败归因、回放和调试 | 二起步，五保留记录，七系统化 |
| 离线评估、回归、完成验证、成本和延迟 | 各阶段验证，七系统化 |
| Orchestrator、子Agent、并发和嵌套限制 | 七 |
| SDK/API、插件规范、模型适配与开发文档 | 一至二建立，六扩展，八收敛 |
| 账户权限、存储/数据库/队列、部署灰度及高可用 | 核心后生产接入专题 |
| RSI/自进化、问题聚类、新技术评估 | 七之后深化，从故障分类与独立回归开始 |

阶段定义与成果见course-design.md。岗位要求用于约束覆盖，不按章节数量推算掌握；学历、年限、生产履历不由课程授予。任何内容完成均需区分作者机制验证与学习者独立表现。

当前内容覆盖：01模型接入；02工具声明、动作请求及协议检查。02尚不覆盖执行层参数验证、权限、工具结果反馈或Runtime调度；这些不因schema声明或固定响应检查而认定已实现。学习者掌握证据仍待独立解释与迁移。

2026-11-03，03新增内容覆盖：Runtime批次执行、JSON解析与工具专用参数检查、实际只读I/O、请求ID关联、应用持有历史及服务消息转换、已知失败反馈/未知异常停止。coding-tools最小包提前隔离具体能力。作者固定响应与真实I/O验证通过；尚无学习者03独立实现和真实模型任务证据。自动循环归04，通用schema校验、取消与预算归二阶段，持久化/隔离/审批等仍待后续。
