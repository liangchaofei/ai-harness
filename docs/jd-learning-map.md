当前内容覆盖：01模型接入；02工具声明、动作请求及协议检查。02尚不覆盖执行层参数验证、权限、工具结果反馈或Runtime调度；这些不因schema声明或固定响应检查而认定已实现。学习者掌握证据仍待独立解释与迁移。

2026-11-03，03新增内容覆盖：Runtime批次执行、JSON解析与工具专用参数检查、实际只读I/O、请求ID关联、应用持有历史及服务消息转换、已知失败反馈/未知异常停止。coding-tools最小包提前隔离具体能力。作者固定响应与真实I/O验证通过；尚无学习者03独立实现和真实模型任务证据。自动循环归04，通用schema校验、取消与预算归二阶段，持久化/隔离/审批等仍待后续。

04已提供：Agent自动循环、运行内存状态归属、模型调用函数注入、完整工具反馈后继续、调用尝试上限、回答/截断/空输出/异常的明确停止，以及应用任务接受检查。作者机制验证与学习者掌握分别记录。多提供商、流式、取消与预算细化仍在第二阶段；不因ModelCall存在而标记这些能力已完成。

2026-11-04，06内容覆盖多模型协议接入、统一模型调用、凭据归属与HTTP传输注入，两个任务复用原Runtime。提供DeepSeek/Anthropic原生编解码，临时固定响应/真实工具/包外消费验证；第二家真实服务无Key待取证，不因此称为已完成生产适配。第二阶段07–12将继续工具契约、事件、流式、取消、整次预算与联调；持久化、安全、编排仍按后续阶段。

2026-11-04，07内容覆盖工具本地schema执行门禁、启动清单检查、已知失败反馈/未知异常停止、受控错误类别与部分执行证据保留；模型配置/HTTP/连接/协议错误归类。未实现自动重试、回滚、持久化恢复或OS沙箱。验证为固定决策/HTTP加真实I/O与包外消费，学习者独立表现仍待取证，下一单元沿事件主线推进。

08内容覆盖：运行过程可观察的第一步。通用Runtime提供模型/工具/停止事件及身份关联，两任务共同消费；应用进度与状态保存分离，观察失败独立计数。不是全链路Tracing、持久化回放、监控平台或生产遥测；后续五/七阶段继续补足。机制验证与学习者独立定位证据分开，不能按八篇推算岗位覆盖百分比。

09内容覆盖：模型流接入、运行中增量观察与可执行消息边界，服务拼接和Runtime状态分离；两协议复用同一事件/执行机制。仍不等于生产协议兼容、取消/恢复、完整遥测或自主任务质量。10/11继续补运行控制，其他生产能力按后续阶段推进。

10内容覆盖运行生命周期主动控制、模型/工具协作取消、迟到结果门禁、部分事实保留与资源清理；是Runtime可靠执行基础，不等于生产抢占、事务回滚或持久化恢复。两任务保留业务职责并消费同一控制接口；固定响应与SIGINT机制证据不计学习者掌握。

11内容覆盖Runtime整次期限、累计工作量预算、跨批额度、停止来源与资源归属；两任务复用同一控制链。边界刷新拒绝迟到结果，不代表硬实时保证、服务端停算、费用/token上限或生产可靠性已全部完成；12用新材料联调，其他JD能力按后续阶段推进。
