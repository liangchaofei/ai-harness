# 18学习卡：第三阶段实践验收

功能：新页面路径任务复用同一个CLI、模型接入、Runtime和代码会话；审阅实际动作、当前变化与匹配验收。

归属：模型选择动作，Runtime保存消息与预算，代码会话保存基线/真实验收，CLI控制进程、报告与交付判断。业务规则留在材料。

最终应用配置：8次模型调用、12项工具、60秒，单次输出上限1024 token。最后一次仍请求工具会被拦；计数、末轮门禁及接受条件不变。

故障区分：toolLimit是工具项额度不足；callLimit是模型轮次不足且最后仍请求工具；truncated是输出截断；有修改但checkMatchesCurrent false仍不能接受。模型提出请求不等于实际执行，工具处理正常不等于业务通过。

证据：作者固定repair 4模型/6工具接受、stale 5/7拒绝、recheck 6/8接受。用户授权作者实际诊断：修订前6/8接受，修订后5/9接受，八项用例通过；另用同一固定轨迹证明原6轮会拦第6轮验收，新8轮可第7轮回答。真实结果与固定机制分别记录，不由两次成功推断稳定成功率或学习者掌握。
