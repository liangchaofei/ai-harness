# 第一阶段：基础原理与首个运行内核

阶段目标：通过公开包入口运行一个能选择工具、执行并利用结果继续的小型Agent；换任务/工具不改循环。它只是最终Runtime/Harness与桌面应用的第一阶段。

| 章节 | 新增行为 | 职责与产物 | 主要验证 |
|---|---|---|---|
| 01 一次模型调用，从包入口到文本结果 | 应用发消息，模型包请求服务并检查返回 | model包、code-review示例；不是完整Agent | 公共包导入、两条消息、正常/失败/截断路径；修改消息再观察 |
| 02 模型提出工具请求 | 让响应表达所需动作，区分文字与工具请求 | 模型包扩展响应协议、示例提供工具说明 | 不把请求当执行、不手写固定动作冒充模型选择 |
| 03 本地执行并反馈结果 | 工具实际执行，结果关联请求后进入下次调用 | runtime起步、应用注入工具与工作范围 | 请求ID配对、实际结果与下一轮输入 |
| 04 自动继续与停止 | 按响应反复推进，程序限制运行边界 | runtime循环，任务不硬编码到循环 | 不同轮数、上限与结束结果；非固定两次调用 |
| 05 换任务检验运行内核 | 替换工具和任务，复用模型与循环 | 独立第二示例，阶段回顾 | 只改接入而不复制核心；解释状态/输入/工具归属 |

01–03已提供正文与候选；04–05为阶段规划，接口与范围在实际实现前核对。相比初步草案，将系统导读合入01，避免用整篇只介绍目录配置。网站预先准备，不作为Agent章节。

01的系统位置是应用→模型接入→服务；没有工具、自动循环或仓库读写。第一版model仅支持DeepSeek文本、不做流式，不提前设计通用provider注册系统。公开complete是当前单提供商教学接口，不是统一行业标准。

读者实现packages/examples；作者只提供site/snippets/01-model-call，候选临时验证不覆盖学习源码。保留已提供/作者验证/学习者独立实现与迁移的分别记录；没有继承旧课程掌握结论。
