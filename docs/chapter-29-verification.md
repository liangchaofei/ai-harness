# 第 29 篇验证记录

第 28 篇基线上叠加实验候选。离线安装，npm run check 通过。固定模型写入实际副本，恢复 CLI 真正启动本地验收进程。实验等待子进程启动，向自己创建的恢复 CLI 发送 SIGKILL，等待退出，再让子进程继续验收。连续三次观察到子进程记录退出码 0、.started 存在、.done 缺失，再次提交退出 2。

实验输出通过临时文件完成后改名。验收观察脚本处理父进程关闭 stdout 管道产生的 EPIPE，以便子进程保留单独的证据。该记录不代替正式验收回执。不测试断电耐久性或任意子进程树恢复。
