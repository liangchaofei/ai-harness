# 17学习卡：终端应用与Agent内核

功能：一个独立命令用可信任务配置接不同代码材料，不为每项任务复制循环。

过程：argv→参数→任务路径解析→绑定服务→创建副本及代码会话→runAgent→真实动作/反馈→inspect→接受→退出码。

归属：CLI持有进程信号、凭据与会话句柄；Runtime持有消息/预算；代码会话持有基线与验收；模型提出动作；操作者提供可信任务与验收。

路径：--task按cwd；JSON内source/checkScript按配置文件目录；writablePaths是副本内相对路径。

证据：0已接受，1未接受，2参数/准备/报告失败，130主动取消。正常回答和计划完成均不保证任务接受。callLimit末轮请求可能未执行。

边界：无依赖ESM小材料、受限文本范围、固定外置脚本；不是OS沙箱、恢复、任意仓库或自动合入。
