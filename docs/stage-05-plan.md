# 第五阶段：可靠执行与恢复

沿用现有 Coding CLI 和 Runtime。先把可观察的任务事实保存下来，再研究哪些状态足以安全地继续执行。

| 单元 | 能力 | 验收 |
|---|---|---|
| 25 会话记录 | 在 CLI 逐段保存 Runtime 已返回的消息和停止原因 | 退出后可读；追问段只追加新消息；拒绝覆盖旧文件 |
| 26 跨进程只读接续 | 从完整日志重建消息并追加追问 | 能引用旧验收；损坏日志在模型调用前拒绝 |
| 27 待验收检查点 | 受控交接后核对旧副本并执行一次验收 | 内容变化拒绝，已占用检查点拒绝重跑 |
| 28 验收完成回执 | 占用和完成分别记录 | 重复提交复用回执，结果不明时停止 |
| 29 真实进程中断 | 在验收子进程已启动时中断恢复 CLI | 子进程留下独立结果，CLI 无回执时拒绝重跑 |
| 30 正式 CLI 恢复诊断 | 查看执行证据并区分可提交、已完成与结果不明 | 只读诊断无副作用，未知状态拒绝重复执行 |

第 25 篇保存的是已结束运行段。段内崩溃、落盘耐久性和执行恢复留给后续单元。

第五阶段以第 30 篇收尾。下一阶段进入权限与人工批准。任意副作用重试与进程树清理仍有待后续专门验证。
