# 04 复习卡：自动循环与停止

主线：Runtime把模型决定→工具执行→完整反馈保存→下一次决定接成循环，模型函数由应用注入。

必须能追踪：初始数组由应用提供；本次messages由Runtime浅复制并追加；每次callModel拿最新数组副本；complete只做协议往返；executeTools只返回完整批次；Runtime push更新；应用接住RunResult再按任务验收。

modelCalls是模型函数调用尝试数，不是工具数、消息数或计费次数。最后一次若仍要工具则callLimit且不执行；最后一次有正常非空回答仍可answered。截断不执行；空文本不交付；未知异常failed并留phase/error供本地调试，不能直接打印整个结果。

answered只证明得到文本；审查示例另查目标源码成功读取，具体问题与计算仍需核对。已知工具失败可以反馈后继续，历史有失败不等于后续必然失败；也不保证模型一定修正。
