# 第七阶段：评估、调试与任务编排

| 单元 | 能力 | 验收 |
| --- | --- | --- |
| 37 结构化运行轨迹 | 保存同一次运行的模型与工具事件 | 同一任务复现因工具额度没有执行验收，对照成功轨迹并定位差异 |
| 38 离线诊断 | 读取既有轨迹，区分结束、截断前缀和计数矛盾 | 无需模型或工具即可生成可核对的停止归因 |
| 39 任务集和基线 | 顺序运行可信任务并保存每项报告和轨迹 | 发票与路径同一清单，通过固定对照观察接受率和工具处理差异 |
| 后续：回归比较 | 按用例对齐两次完整测量 | 区分退化、改善和缺少可比证据 |
| 后续：委派与汇合 | 在单 Agent 基线上引入有限委派与取消 | 记录子任务身份、权限与结果汇合，比较成本与质量 |

阶段安排沿用课程路线。将运行轨迹用于诊断和评估之前，先确认哪些事件是请求、哪些表示实际处理、哪些结果来自独立的业务验收。
