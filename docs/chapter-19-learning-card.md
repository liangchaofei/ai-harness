# 19 学习卡：完整记录与本轮输入

问题：应用改变下一次模型可见信息时，不能删改真实任务、请求和工具反馈。

数据链：循环messages→当前结构副本→可选prepareMessages→返回消息副本→Context→callModel→完整响应/真实工具结果追加回原messages。准备结果不写回历史。

默认全量，无新CLI开关。当前副本覆盖消息对象与assistant.toolCalls的数组/对象；不是任意结构深复制或安全沙箱。应用回调负责信息与工具关系，不验证语义。

固定真实读取观察：full输入1/3，note输入2/4，正常最终都是4条记录；note提示不进历史。broken第二次准备失败：input/input_preparation，1模型/1工具/3条历史，保留真实反馈。准备失败、取消或到期都不启动迟到模型调用，忽略信号的回调仍可能一直等待。
