19 完整运行记录与本轮模型输入 ​

第 18 篇里，CLI 能把模型请求、真实工具反馈和最终交付判断连起来。任务继续变长时，会遇到一个新问题：如果只想改变下一次提供给模型的信息，应该改哪里，才能保留已经发生的事实？

本篇在每次模型调用之前加入消息准备步骤。默认仍提供全部历史；应用也可以额外加入一条只对本轮有效的提示。模型使用准备后的输入继续决策，最终报告仍保留原始任务、实际请求和真实工具反馈。

这是第四阶段“长任务的信息管理”的起点。本篇先建立输入准备的位置与状态归属，后续再处理有限输入、摘要、记忆检索和同任务多轮交互。继续使用现有 Runtime 和 apps/coding-cli，不创建另一套循环。

本篇技术方案 ​

实施前，先走完一次具体过程 ​

沿用页面路径材料。这里先观察“读取当前实现”这一步，不再增加新的业务规则。

1. Runtime 保存已经发生的事实 ​

第一次调用模型前，记录只有用户任务。模型请求 read_file，实际工具返回 normalize.ts 的文本后，记录变为三条：用户任务、assistant 工具请求、toolResult 真实反馈。

这三条由原循环依次保存。请求 ID read_current 连接“模型要求读取什么”和“本地实际返回什么”；下一轮必须能够根据真实反馈继续。

2. 为下一次调用单独准备一份输入 ​

应用希望下一次模型用简短中文说明取得的材料。它可以在这三条消息的副本后面加一条提示，得到四条本轮输入。

这条提示由应用临时提供，不是用户刚发出的新消息，也不是工具执行结果。因此本篇不把它追加到完整运行记录。下一轮准备时仍从真实记录开始，不会累计出越来越多条相同提示。

3. 模型读取本轮输入，Runtime 保存实际响应 ​

Runtime 把准备好的四条消息交给原来的模型调用函数。真实服务路径仍由模型包编码请求和解码响应；固定观察则由本地函数返回预写响应。

收到完整回答后，循环把这条实际 assistant 响应追加到原来的三条记录。于是模型刚才看到四条，最终记录也恰好是四条，但内容不同：前者多了临时提示，后者多了实际回答。不能只比较条数就认定两份数据相同。

4. 报告继续读取完整记录和实际验收 ​

CLI 的历史报告仍读 result.messages，代码任务的接受判断仍读同会话 inspect()。改变本轮输入不自动产生验收证据，也不能通过一条“已通过”的临时提示让应用接受任务。

实现架构图 ​

本篇的“完整记录”指 Runtime 在内存中保存的初始消息、完整模型响应和工具反馈。它不是原始 HTTP 抓包，不包含未完成的流式草稿，也尚未落盘。这里的“本轮输入”指交给 callModel 的 Context：系统要求、准备后的消息和工具说明；提供商随后还会转换协议格式。

为什么不能直接改循环里的 messages ​

此前模型调用使用 messages: [...messages]，复制了数组，但数组里的消息对象仍共享。若应用直接删除历史消息，报告就失去了原始事实；若只复制数组后改 message.content 或 assistant.toolCalls[0]，仍可能改到原对象。

本篇让准备函数和模型函数都使用独立的消息对象。复制范围明确覆盖当前文本消息，以及 assistant 中的工具请求数组和各请求对象。字符串作为值传递；将来引入图片或其他嵌套结构时，要重新检查这段复制逻辑，不能永久假定它覆盖所有数据。

输入准备也是一项可信应用能力。它可以影响模型判断，所以本篇只展示“保留全部消息，再加临时提示”，不提供默认裁剪。随意删除请求、只保留对应工具反馈，可能破坏模型协议或丢失任务依据；复制只保护历史，不能证明选择策略正确。

与 Pi 的职责对照 ​

固定版本 Pi 的 streamAssistantResponse 在模型调用前先执行可选 transformContext，再用 convertToLlm 转成模型消息。实际响应继续写入运行上下文；本轮转换和历史保存有各自的位置。

它的 AgentLoopConfig 允许更丰富的 Agent 消息，并要求这些回调不要抛错。本项目目前只有统一的 Message，因此只引入一个消息准备回调，不照搬转换层；同时选择复制消息、把准备异常归为受控失败。这些是本项目的实现选择，不能据同名职责声称行为完全等价。

新建 packages/runtime/src/types/input.ts。它约定应用怎样提供消息准备函数，以及循环怎样把系统要求、工具说明和信号交给包内组装函数。类型只描述契约，不创建消息或执行回调。

ts
// 【新增文件】本轮消息准备与Runtime内部组装配置。
import type { Context, Message, ToolDefinition } from '@ai-harness/model';

/**
 * 应用提供，Runtime在每次模型调用前等待；输入是独立消息副本。
 * 返回值仅用于本轮输入，不替换完整记录。省略时保留全部消息。
 * 可信应用须保留任务依据与工具请求/反馈关系；此类型不做语义验证。
 */
export type PrepareMessages = (
  history: readonly Message[],
  signal: AbortSignal,
) => readonly Message[] | Promise<readonly Message[]>;

/** Runtime创建并交给包内输入组装函数；不从公开入口导出。 */
export interface InputPreparationOptions {
  /** 沿用本次运行配置的系统要求，准备回调不能通过返回值替换它。 */
  systemPrompt?: Context['systemPrompt'];
  /** 从实际工具注册表生成的说明，不包含execute。 */
  tools: readonly ToolDefinition[];
  /** 应用可选的本轮消息转换；失败将停止本次运行。 */
  prepareMessages?: PrepareMessages;
  /** 与模型和工具共用整次运行信号；准备函数应协作取消。 */
  signal: AbortSignal;
}

PrepareMessages 的第一个参数是历史的独立副本；函数可以同步返回，也可以等待后返回消息数组。第二个参数是本次运行的信号，供等待外部材料的准备过程协作取消。

例如传入三条历史，返回原三条加一条提示，只有返回值进入本轮输入。函数不是工具，不由模型请求，也不占工具额度。readonly Message[] 限制经此类型增删数组，不会自动冻结其中的对象；真正的历史保护由下一步的复制完成。

InputPreparationOptions 只在包内使用。系统要求和工具说明仍由运行配置与真实注册表提供，准备函数只返回消息，不返回任意工具执行能力。

完整替换 packages/runtime/src/types/run.ts。保留 RunAgentOptions、RunOutcome、RunResult 及原预算、事件和停止状态；新增可选 prepareMessages，说明初始消息复制范围，并让失败的 phase 支持 'input'。它让调用方能接入策略，让报告能识别输入准备失败。

ts
// 一次运行的配置与停止结果。
import type { AssistantMessage, Message } from '@ai-harness/model';
import type { ModelCall } from './model-call';
import type { PrepareMessages } from './input';
import type { RunFailure } from './failures';
import type { ExecutableTool } from './tools';
// 应用可以接收本次运行的动作通知。
import type { RunEventListener } from './events';

/** 应用创建运行配置；任务与模型连接不写入通用循环。 */
export interface RunAgentOptions {
  /** 初始记录；Runtime复制当前消息结构后追加，不修改调用方的消息。 */
  messages: readonly Message[];
  /** 可省略的总体要求，每次模型调用沿用。 */
  systemPrompt?: string;
  /** 本次允许使用的本地工具；Runtime 仅把说明交给 callModel。 */
  tools: readonly ExecutableTool[];
  /** 应用绑定服务配置和凭据的函数，Runtime 不选择提供商。 */
  callModel: ModelCall;
  // 【新增】本轮输入可以变化，完整记录仍由Runtime追加。
  /** 每次调用模型前等待；省略保留全量消息。失败在input阶段停止，不计入模型调用次数。 */
  prepareMessages?: PrepareMessages;
  /** 整次运行最多发起的模型调用数，正安全整数；包括最终回答和失败的调用。 */
  maxModelCalls: number;
  // 整次经过时长与工具处理次数分别限制，不是 token 或费用估算。
  /** 从有效 runAgent 启动到选定停止原因的期限，1..2147483647 毫秒；省略不设整次期限。 */
  timeoutMs?: number;
  /** 累计可进入处理的工具请求数，非负安全整数；含坏参数/未知名称，0 表示不处理工具。省略不另设限制。 */
  maxToolCalls?: number;
  // 不提供时仍按原循环运行。
  /** 可选观察函数；被依次等待，失败被计数；返回值不改变状态。取消须由应用另行触发 controller。 */
  onEvent?: RunEventListener;
  // 应用持有 controller，Runtime 只读取信号。
  /** 触发后停止新动作；等待当前协作操作退出。不会强杀不响应信号的操作。 */
  signal?: AbortSignal;
}

/** 各种停止结果共用的运行记录，由 Runtime 创建并交给应用读取。 */
interface RunRecord {
  /** 已保存的初始消息、模型响应和工具结果；未知批次异常时含此前已完成项，只在内存中。 */
  messages: readonly Message[];
  /** 实际发起的模型调用次数，不是工具次数或消息条数。 */
  modelCalls: number;
  // 由 Runtime 在进入单项处理前累计，不等于成功结果或实际 I/O 数量。
  /** 已开始处理的工具请求数；包括 tool_start 通知后被取消、参数被拒绝的项。 */
  toolCalls: number;
}

/** 包内先构造的停止结果；answered 也不保证任务结论正确。 */
export type RunOutcome = RunRecord &
  (
    | { status: 'answered'; answer: AssistantMessage }
    // 主动停止，保留已有完整记录；无 answer/failure，不表示可直接恢复。
    // 本分支在 cancelled 之外增加 timedOut；两者都保留记录，不携带答案或执行故障。
    | { status: 'cancelled' | 'timedOut' }
    // callLimit 为模型上限，toolLimit 为下一项工具额度不足；其他停止含义保留。
    | { status: 'callLimit' | 'toolLimit' | 'truncated' | 'emptyAnswer' }
    // 未知异常不作为工具反馈；保留原异常仅供本地调试，不能直接打印整个结果。
    | {
        status: 'failed';
        phase: 'input' | 'model' | 'tools';
        failure: RunFailure;
        error: unknown;
      }
  );

// 对外结果附运行身份与观察失败数，原有停止联合保留。
/** Runtime 返回给应用；runId 可与实时事件对齐，观察失败不改变任务停止原因。 */
export type RunResult = RunOutcome & {
  /** 与本次所有事件的 runId 相同，不表示已创建持久化会话。 */
  runId: string;
  /** onEvent 抛错或 Promise 拒绝的次数，包括 run_end；没有监听方时为 0。 */
  observerErrors: number;
};

旧应用没有传 prepareMessages 时，仍然保留全量消息。modelCalls 继续表示真正发起的模型调用数：如果准备第一轮输入就失败，模型还没调用，因此次数为 0。

phase:'input' 不是新增一种业务验收结果。它与模型服务失败、工具执行失败分开，方便知道应该去检查应用准备函数，而不是先怀疑网络或修改代码工具。

完整替换 packages/runtime/src/types/failures.ts。保留原失败类别和 RunFailure 字段，只新增 input_preparation，供循环生成不含输入正文的失败说明。

  | `model_${ModelFailureKind}`
  | 'model_unknown'
  | 'tool_configuration'
  | 'tool_protocol'
  | 'tool_execution';

  code: RunFailureCode;
  /** 由框架生成的受控说明，原始异常另留在 RunResult.error。 */
  message: string;
  /** 仅工具执行异常时关联当项；不是断点恢复句柄。 */

// Runtime 发出的动作摘要；应用接收，不参与模型消息协议。
import type { AssistantMessage } from '@ai-harness/model';
import type { RunFailureCode } from './failures';

/** 单项通知沿用原请求身份；执行器填入，不另外生成模型请求 ID。 */
interface ToolIdentity {
  /** 原 assistant.toolCalls 中该项的 id。 */
  toolCallId: string;
  /** 原请求的工具名，即使没有注册该名称，也保留它用于定位。 */
  toolName: string;
}

/** 执行器创建单项处理通知；runAgent 补上所属模型调用次数。仅包内使用。 */
export type ToolEventData = ToolIdentity &
  (
    | { type: 'tool_start' }
    // 只扩展本事件的含义，字段不变：运行信号可来自主动取消或到期，原因见 run_end.status。
    | { type: 'tool_cancelled' }
    | {
        type: 'tool_end';
        /** true 为已形成失败反馈；false 为成功结果，尚不代表整批已写入循环历史。 */
        isError: boolean;
      }
    | {
        type: 'tool_failed';
        /** 无法形成普通反馈的停止错误；原始异常不进入事件。 */
        code: RunFailureCode;
      }
  );

/** Runtime 各边界提供的摘要；事件派发器另补运行身份与顺序号。仅包内使用。 */
export type RunEventData =
  | { type: 'run_start' }
  // 【新增】这是本轮Context条数，不是HTTP消息数、token或额外调用。
  | {
      type: 'input_prepared';
      /** 接下来拟发起的模型调用序号；观察期间取消时不一定实际发起。 */
      modelCall: number;
      /** 准备前完整运行记录中的消息条数。 */
      historyMessageCount: number;
      /** 准备后本轮Context.messages中的消息条数。 */
      inputMessageCount: number;
    }
  // 只扩展本事件的含义，字段不变：模型等待因运行信号停止，原因见 run_end.status。
  | { type: 'model_cancelled'; modelCall: number }
  // 预览不作为消息写入，流失败后也不能当作最终回答。
  | {
      type: 'model_text_delta';
      /** 当前模型调用序号，复用同一次调用而非发起新调用。 */
      modelCall: number;
      /** 本次新增文字；应用可以展示，不能据此执行工具。 */
      text: string;
    }
  | {
      type: 'model_start';
      /** 即将开始的模型调用序号，从 1 开始；若观察期间取消，实际调用尚未计数。 */
      modelCall: number;
    }
  | {
      type: 'model_end';
      /** 刚取得完整消息的模型调用序号。 */
      modelCall: number;
      /** 完整消息的停止原因，不等于整次任务的停止原因。 */

      /** 完整响应中请求的工具项数，不是已执行数量。 */
      toolCallCount: number;

      type: 'model_failed';
      /** 失败的模型调用序号；仍计入本次调用预算。 */

      /** Runtime 生成的稳定失败类别，不附原始异常正文。 */
      code: RunFailureCode;
    }
  | (ToolEventData & {
      /** 提出这些请求的模型调用序号；同批多个工具项共用该值。 */
      modelCall: number;
    })
  | {
      type: 'run_end';
      /** 与随后返回的 RunResult.status 一致，answered 也不保证答案正确。 */
      status:
        | 'answered'
        | 'callLimit'
        | 'truncated'
        | 'emptyAnswer'
        | 'failed'
        | 'cancelled'
        // 整次期限到达；不同于用户主动取消或单次 HTTP 失败。

        // 准备处理下一项工具请求时，累计处理额度不足。
        | 'toolLimit';

      modelCalls: number;
      // 让观察方无需等待最终结果，就能从停止事件取得累计处理数。
      /** finish 从 outcome.toolCalls 复制；含参数被拒绝的尝试，不是请求数组或成功次数。 */
      toolCalls: number;
      /** 仅 status 为 failed 时有值；没有值不表示任务验收通过。 */
      failureCode?: RunFailureCode;
    };

/** Runtime 创建，应用观察；只含原始值；文字片段仅作预览，不附参数、历史或原始异常。 */

  RunEventData & {
    /** 同一次 runAgent 的关联身份；不同运行不共用，由 Runtime 生成。 */
    runId: string;

第二步：从历史副本组装本轮输入 ​

新建 packages/runtime/src/context/prepare-input.ts。这份代码替循环完成“复制记录 → 等待应用准备 → 再复制返回值 → 组成 Context”。例如历史为三条、应用补一条提示，函数返回含四条消息的 Context，下一步由循环交给模型；它不会把提示写回历史。

ts
// 【新增文件】从完整记录构造独立的本轮模型输入。
import type { Context, Message } from '@ai-harness/model';
import type { InputPreparationOptions } from '../types/input';

/**
 * Runtime内部复制当前文本消息结构：数组、消息对象及assistant工具请求对象。
 * 字符串是值；若以后加入图片或其他嵌套对象，需要重新检查复制范围。
 */
export function copyMessages(messages: readonly Message[]): Message[] {
  return messages.map((message) => {
    if (message.role === 'assistant') {
      return {
        ...message,
        toolCalls: message.toolCalls.map((call) => ({ ...call })),
      };
    }

    return { ...message };
  });
}

/**
 * 循环在调用模型前等待；history只提供事实来源，不被本函数改写。
 * 输入、回调返回值与模型接收的消息分别复制，避免共享对象污染历史。
 */
export async function prepareModelInput(
  history: readonly Message[],
  options: InputPreparationOptions,
): Promise<Context> {
  options.signal.throwIfAborted();

  const snapshot = copyMessages(history);
  const selected = options.prepareMessages
    ? await options.prepareMessages(snapshot, options.signal)
    : snapshot;

  // 协作操作即使返回迟到结果，也不能继续启动模型。
  options.signal.throwIfAborted();
  if (!Array.isArray(selected) || selected.length === 0) {
    throw new Error('本轮输入必须返回非空消息数组。');
  }

  return {
    systemPrompt: options.systemPrompt,
    messages: copyMessages(selected),
    tools: options.tools,
  };
}

copyMessages 复制哪些对象 ​

对 user 和 toolResult，当前字段只有原始值，所以复制消息对象即可。对 assistant，还要复制 toolCalls 数组及每个请求对象。这样应用即使修改某个副本的 toolCalls[0].arguments，完整记录里的原请求参数也不会一起改变。

这个函数同时用于初始记录、交给准备回调的副本，以及交给模型的最终消息。三处复制分别防止调用方初始对象、准备函数和模型输入继续共享当前消息结构。

prepareModelInput 怎样返回给调用方 ​

history 是完整记录，snapshot 是交给应用的副本，selected 接住应用返回的消息数组。没有回调时，selected 就是完整副本；有回调时，可以是三条历史加一条提示。

最后创建的 Context 保留运行配置中的 systemPrompt 和从注册表生成的 tools，只将 messages 设置为准备后的另一份副本。返回值不会自动更新历史，下一步调用方用局部变量接住它。

回调等待结束后还要检查信号，因为取消或到期可能发生在等待期间。Node 的 AbortSignal 提供取消状态和抛错检查；本项目还会在循环中核对整次时限。若回调忽略信号且一直不结束，Runtime 仍会等待，不能把协作取消说成强制终止。

非空数组检查用于拒绝明显无效的返回值。它没有检查每条消息的全部字段，也不验证工具请求/结果是否配对或提示是否真实。准备逻辑属于可信应用代码；后续选择策略仍需要独立验证。

// 循环保留历史和计数，期限与取消交给独立控制模块。
import { ModelCallError, type AssistantMessage, type Context } from '@ai-harness/model';
import type { RunAgentOptions, RunResult, RunOutcome } from './types/run';
import type { RunControl } from './types/run-control';
import type { RegisteredTool } from './types/tool-registry';

import { ToolBatchCancelled } from './errors/tool-batch-cancelled';

import { createToolRegistry } from './tools/registry';

/** 应用调用一次；合法配置后开始整次期限，所有出口都清理控制资源。 */
export async function runAgent(options: RunAgentOptions): Promise<RunResult> {
  if (!Number.isSafeInteger(options.maxModelCalls) || options.maxModelCalls < 1) {
    throw new Error('maxModelCalls 必须为正安全整数。');
  }
  if (options.messages.length === 0) {
    throw new Error('初始消息不能为空。');
  }
  // 预算配置出错时不启动模型或工具。
  if (
    options.maxToolCalls !== undefined &&
    (!Number.isSafeInteger(options.maxToolCalls) || options.maxToolCalls < 0)
  ) {
    throw new Error('maxToolCalls 必须为非负安全整数。');
  }
  // 在有效运行入口创建期限控制，结束时统一释放。
  const control = createRunControl(options.signal, options.timeoutMs);
  try {
    return await runLoop(options, control);
  } finally {
    control.dispose();
  }
}

/** 只在包内使用：持有本次消息/计数，不创建计时器或进程监听。 */
async function runLoop(
  options: RunAgentOptions,
  control: RunControl,
): Promise<RunResult> {
  // 【修改】独立持有初始消息及其工具请求对象。
  const messages = copyMessages(options.messages);
  let modelCalls = 0;
  // 计数由循环持有；执行器通过下面的回调申请一次处理额度。
  let toolCalls = 0;
  const events = createRunEvents(options.onEvent);
  await events.emit({ type: 'run_start' });

  async function finish(outcome: RunOutcome): Promise<RunResult> {
    // 停止原因选定后清理计时器，不把 run_end 展示算成任务超时。
    control.dispose();
    await events.emit({
      type: 'run_end',
      status: outcome.status,
      modelCalls: outcome.modelCalls,
      toolCalls: outcome.toolCalls,
      failureCode: outcome.status === 'failed' ? outcome.failure.code : undefined,
    });
    return {
      ...outcome,
      runId: events.runId,
      observerErrors: events.errorCount(),
    };
  }
  // 替代原 cancel：根据控制对象区分主动取消和整次到期。
  function finishStopped(): Promise<RunResult> {
    const status = control.stopStatus();
    if (!status) {
      throw new Error('尚未收到运行停止请求。');
    }
    return finish({
      status,
      messages,
      modelCalls,
      toolCalls,
    });
  }
  // 工具执行器每处理一项前调用；总计数仍只在此处更新。
  function tryStartToolCall(): boolean {
    if (options.maxToolCalls !== undefined && toolCalls >= options.maxToolCalls) {
      return false;
    }
    toolCalls += 1;
    return true;
  }
  if (control.stopStatus()) {
    return finishStopped();
  }

  let registry: ReadonlyMap<string, RegisteredTool>;
  try {
    registry = createToolRegistry(options.tools);
  } catch (error) {
    if (!(error instanceof ToolBatchError)) {
      throw error;
    }
    return finish({
      status: 'failed',
      phase: 'tools',
      failure: error.failure,
      error,
      messages,
      modelCalls,
      toolCalls,
    });
  }
  const definitions = [...registry.values()].map(
    ({ name, description, parameters }) => ({
      name,
      description,
      parameters,
    }),
  );

  while (modelCalls < options.maxModelCalls) {
    // 不只检查外部取消，还刷新整次期限。
    if (control.stopStatus()) {
      return finishStopped();
    }
    const nextCall = modelCalls + 1;
    // 【新增】本轮输入仅交给callModel，不回写messages。
    let context: Context;
    try {
      context = await prepareModelInput(messages, {
        systemPrompt: options.systemPrompt,
        tools: definitions,
        prepareMessages: options.prepareMessages,
        signal: control.signal,
      });
    } catch (error) {
      if (control.stopStatus()) {
        return finishStopped();
      }

      return finish({
        status: 'failed',
        phase: 'input',
        failure: {
          code: 'input_preparation',
          message: '本轮模型输入准备失败。',
        },
        error,
        messages,
        modelCalls,
        toolCalls,
      });
    }
    if (control.stopStatus()) {
      return finishStopped();
    }

    await events.emit({
      type: 'input_prepared',
      modelCall: nextCall,
      historyMessageCount: messages.length,
      inputMessageCount: context.messages.length,
    });
    if (control.stopStatus()) {
      return finishStopped();
    }

    await events.emit({
      type: 'model_start',
      modelCall: nextCall,
    });
    if (control.stopStatus()) {
      return finishStopped();
    }
    modelCalls = nextCall;
    let message: AssistantMessage;
    try {
      message = await options.callModel(
        // 【修改】只交出本轮输入，不替换完整记录。
        context,
        async (text) => {
          // 预览也刷新期限；只有仍在运行时才通知。
          if (!control.stopStatus()) {
            await events.emit({
              type: 'model_text_delta',
              modelCall: modelCalls,
              text,
            });
          }
        },
        control.signal,
      );
      if (control.stopStatus()) {
        await events.emit({
          type: 'model_cancelled',
          modelCall: modelCalls,
        });
        return finishStopped();
      }
    } catch (error) {
      if (control.stopStatus()) {
        await events.emit({
          type: 'model_cancelled',
          modelCall: modelCalls,
        });
        return finishStopped();
      }
      const failure =
        error instanceof ModelCallError
          ? {
              code: `model_${error.kind}` as const,
              message: error.message,
              httpStatus: error.httpStatus,
            }
          : {
              code: 'model_unknown' as const,
              message: '模型调用函数发生未分类异常。',
            };
      await events.emit({
        type: 'model_failed',
        modelCall: modelCalls,
        code: failure.code,
      });
      return finish({
        status: 'failed',
        phase: 'model',
        failure,
        error,
        messages,
        modelCalls,
        toolCalls,
      });
    }
    messages.push(message);
    await events.emit({
      type: 'model_end',
      modelCall: modelCalls,
      stopReason: message.stopReason,
      toolCallCount: message.toolCalls.length,
    });
    if (control.stopStatus()) {
      return finishStopped();
    }

    if (message.stopReason === 'length') {
      return finish({
        status: 'truncated',
        messages,
        modelCalls,
        toolCalls,
      });
    }
    if (message.stopReason === 'stop') {
      if (!message.content.trim()) {
        return finish({
          status: 'emptyAnswer',
          messages,
          modelCalls,
          toolCalls,
        });
      }
      return finish({
        status: 'answered',
        answer: message,
        messages,
        modelCalls,
        toolCalls,
      });
    }
    // 保留旧规则：没有机会把结果交回模型的最后一批不执行。
    if (modelCalls === options.maxModelCalls) {
      return finish({
        status: 'callLimit',
        messages,
        modelCalls,
        toolCalls,
      });
    }
    try {
      // 具名传入通知、运行信号、时间刷新和预算申请；执行器不持有全局计数。
      const results = await executeToolBatch(message, registry, {
        signal: control.signal,
        notify: (event) =>
          events.emit({
            ...event,
            modelCall: modelCalls,
          }),
        checkStop: () => {
          control.stopStatus();
        },
        tryStartToolCall,
      });
      messages.push(...results);
    } catch (error) {
      if (error instanceof ToolBatchCancelled) {
        messages.push(...error.completedResults);
        return finishStopped();
      }
      // 工具额度不足保留此前项，不再请求模型或执行超额项。
      if (error instanceof ToolBatchLimit) {
        messages.push(...error.completedResults);
        return finish({
          status: 'toolLimit',
          messages,
          modelCalls,
          toolCalls,
        });
      }
      if (error instanceof ToolBatchError) {
        messages.push(...error.completedResults);
        return finish({
          status: 'failed',
          phase: 'tools',
          failure: error.failure,
          error,
          messages,
          modelCalls,
          toolCalls,
        });
      }
      return finish({
        status: 'failed',
        phase: 'tools',
        error,
        messages,
        modelCalls,
        toolCalls,
        failure: {
          code: 'tool_execution',
          message: '工具调度发生未知异常。',
        },
      });
    }
  }
  throw new Error('运行计数异常。');
}

用同一次读取追踪两份消息 ​

第一次循环，messages 只有用户任务。prepareModelInput 返回本轮 context，然后才发出输入准备事件、模型开始事件，并更新 modelCalls。

await options.callModel(context, ...) 接住完整 assistant 响应。循环仍通过原来的 messages.push(message) 保存实际响应；如果是工具请求，原执行器处理完后，仍通过 messages.push(...results) 保存真实反馈。

第二次循环的 messages 因而是三条。若应用增加临时提示，本次 context.messages 是四条，但代码没有 messages = context.messages，也没有把整个 context 追加回历史。

下面两句是上方实现的对照摘录，无需再次写入：

typescript
const messages = copyMessages(options.messages);
// 每次循环仅将本轮context交给模型，后续仍向messages追加实际响应与反馈。

messages 归循环持有，context 只服务这一轮调用。模型包收到 context 后才转换为服务消息、发送请求并解码响应；解码返回的 assistant 消息沿 callModel 返回到循环，由上面的实际追加语句保存。它不会因为输入里有临时提示就自动把提示写进记录。

准备失败为什么不消耗一次模型调用 ​

准备逻辑放在更新 modelCalls 之前。回调抛错或返回空数组时，循环返回 failed / input / input_preparation，保留已有记录；不会发送 model_start，也不会调用服务。

如果失败实际上来自运行已经取消或到期，先沿原停止出口返回 cancelled 或 timedOut。准备返回后与输入事件之后也检查停止，避免迟到结果或观察期间取消启动下一动作。这里没有自动重试或静默回退：应用未能准备输入时，框架不会擅自换一种信息集合继续决策。

模型调用额度仍包括真正发起但失败的模型请求；工具额度、最后一轮不执行工具的规则和完整回答/截断的判断都没有改变。

  prepareMessages?: PrepareMessages;

  maxModelCalls: number;

        | 'callLimit'

// 【新增文件】从完整记录构造独立的本轮模型输入。
import type { Context, Message } from '@ai-harness/model';
import type { InputPreparationOptions } from '../types/input';

/**
 * Runtime内部复制当前文本消息结构：数组、消息对象及assistant工具请求对象。
 * 字符串是值；若以后加入图片或其他嵌套对象，需要重新检查复制范围。
 */
export function copyMessages(messages: readonly Message[]): Message[] {
  return messages.map((message) => {
    if (message.role === 'assistant') {
      return {
        ...message,
        toolCalls: message.toolCalls.map((call) => ({ ...call })),
      };
    }

    return { ...message };
  });
}

/**
 * 循环在调用模型前等待；history只提供事实来源，不被本函数改写。
 * 输入、回调返回值与模型接收的消息分别复制，避免共享对象污染历史。
 */
export async function prepareModelInput(
  history: readonly Message[],
  options: InputPreparationOptions,
): Promise<Context> {
  options.signal.throwIfAborted();

  const snapshot = copyMessages(history);
  const selected = options.prepareMessages
    ? await options.prepareMessages(snapshot, options.signal)
    : snapshot;

  // 协作操作即使返回迟到结果，也不能继续启动模型。
  options.signal.throwIfAborted();
  if (!Array.isArray(selected) || selected.length === 0) {
    throw new Error('本轮输入必须返回非空消息数组。');
  }

  return {
    systemPrompt: options.systemPrompt,
    messages: copyMessages(selected),
    tools: options.tools,
  };
}

// 循环保留历史和计数，期限与取消交给独立控制模块。
import { ModelCallError, type AssistantMessage, type Context } from '@ai-harness/model';
import type { RunAgentOptions, RunResult, RunOutcome } from './types/run';
import type { RunControl } from './types/run-control';
import type { RegisteredTool } from './types/tool-registry';
import { ToolBatchError } from './errors/tool-batch-error';
import { ToolBatchCancelled } from './errors/tool-batch-cancelled';
import { ToolBatchLimit } from './errors/tool-batch-limit';
import { createToolRegistry } from './tools/registry';
import { executeToolBatch } from './tools/execute';
import { createRunEvents } from './events/dispatcher';
import { createRunControl } from './control/run-control';
// 【新增】输入组装与完整历史分离，复制细节不堆进循环。
import { copyMessages, prepareModelInput } from './context/prepare-input';

/** 应用调用一次；合法配置后开始整次期限，所有出口都清理控制资源。 */
export async function runAgent(options: RunAgentOptions): Promise<RunResult> {
  if (!Number.isSafeInteger(options.maxModelCalls) || options.maxModelCalls < 1) {
    throw new Error('maxModelCalls 必须为正安全整数。');
  }
  if (options.messages.length === 0) {
    throw new Error('初始消息不能为空。');
  }
  // 预算配置出错时不启动模型或工具。
  if (
    options.maxToolCalls !== undefined &&
    (!Number.isSafeInteger(options.maxToolCalls) || options.maxToolCalls < 0)
  ) {
    throw new Error('maxToolCalls 必须为非负安全整数。');
  }
  // 在有效运行入口创建期限控制，结束时统一释放。
  const control = createRunControl(options.signal, options.timeoutMs);
  try {
    return await runLoop(options, control);
  } finally {
    control.dispose();
  }
}

/** 只在包内使用：持有本次消息/计数，不创建计时器或进程监听。 */
async function runLoop(
  options: RunAgentOptions,
  control: RunControl,
): Promise<RunResult> {
  // 【修改】独立持有初始消息及其工具请求对象。
  const messages = copyMessages(options.messages);
  let modelCalls = 0;
  // 计数由循环持有；执行器通过下面的回调申请一次处理额度。
  let toolCalls = 0;
  const events = createRunEvents(options.onEvent);
  await events.emit({ type: 'run_start' });

  async function finish(outcome: RunOutcome): Promise<RunResult> {
    // 停止原因选定后清理计时器，不把 run_end 展示算成任务超时。
    control.dispose();
    await events.emit({
      type: 'run_end',
      status: outcome.status,
      modelCalls: outcome.modelCalls,
      toolCalls: outcome.toolCalls,
      failureCode: outcome.status === 'failed' ? outcome.failure.code : undefined,
    });
    return {
      ...outcome,
      runId: events.runId,
      observerErrors: events.errorCount(),
    };
  }
  // 替代原 cancel：根据控制对象区分主动取消和整次到期。
  function finishStopped(): Promise<RunResult> {
    const status = control.stopStatus();
    if (!status) {
      throw new Error('尚未收到运行停止请求。');
    }
    return finish({
      status,
      messages,
      modelCalls,
      toolCalls,
    });
  }
  // 工具执行器每处理一项前调用；总计数仍只在此处更新。
  function tryStartToolCall(): boolean {
    if (options.maxToolCalls !== undefined && toolCalls >= options.maxToolCalls) {
      return false;
    }
    toolCalls += 1;
    return true;
  }
  if (control.stopStatus()) {
    return finishStopped();
  }

  let registry: ReadonlyMap<string, RegisteredTool>;
  try {
    registry = createToolRegistry(options.tools);
  } catch (error) {
    if (!(error instanceof ToolBatchError)) {
      throw error;
    }
    return finish({
      status: 'failed',
      phase: 'tools',
      failure: error.failure,
      error,
      messages,
      modelCalls,
      toolCalls,
    });
  }
  const definitions = [...registry.values()].map(
    ({ name, description, parameters }) => ({
      name,
      description,
      parameters,
    }),
  );

  while (modelCalls < options.maxModelCalls) {
    // 不只检查外部取消，还刷新整次期限。
    if (control.stopStatus()) {
      return finishStopped();
    }
    const nextCall = modelCalls + 1;
    // 【新增】本轮输入仅交给callModel，不回写messages。
    let context: Context;
    try {
      context = await prepareModelInput(messages, {
        systemPrompt: options.systemPrompt,
        tools: definitions,
        prepareMessages: options.prepareMessages,
        signal: control.signal,
      });
    } catch (error) {
      if (control.stopStatus()) {
        return finishStopped();
      }

      return finish({
        status: 'failed',
        phase: 'input',
        failure: {
          code: 'input_preparation',
          message: '本轮模型输入准备失败。',
        },
        error,
        messages,
        modelCalls,
        toolCalls,
      });
    }
    if (control.stopStatus()) {
      return finishStopped();
    }

    await events.emit({
      type: 'input_prepared',
      modelCall: nextCall,
      historyMessageCount: messages.length,
      inputMessageCount: context.messages.length,
    });
    if (control.stopStatus()) {
      return finishStopped();
    }

    await events.emit({
      type: 'model_start',
      modelCall: nextCall,
    });
    if (control.stopStatus()) {
      return finishStopped();
    }
    modelCalls = nextCall;
    let message: AssistantMessage;
    try {
      message = await options.callModel(
        // 【修改】只交出本轮输入，不替换完整记录。
        context,
        async (text) => {
          // 预览也刷新期限；只有仍在运行时才通知。
          if (!control.stopStatus()) {
            await events.emit({
              type: 'model_text_delta',
              modelCall: modelCalls,
              text,
            });
          }
        },
        control.signal,
      );
      if (control.stopStatus()) {
        await events.emit({
          type: 'model_cancelled',
          modelCall: modelCalls,
        });
        return finishStopped();
      }
    } catch (error) {
      if (control.stopStatus()) {
        await events.emit({
          type: 'model_cancelled',
          modelCall: modelCalls,
        });
        return finishStopped();
      }
      const failure =
        error instanceof ModelCallError
          ? {
              code: `model_${error.kind}` as const,
              message: error.message,
              httpStatus: error.httpStatus,
            }
          : {
              code: 'model_unknown' as const,
              message: '模型调用函数发生未分类异常。',
            };
      await events.emit({
        type: 'model_failed',
        modelCall: modelCalls,
        code: failure.code,
      });
      return finish({
        status: 'failed',
        phase: 'model',
        failure,
        error,
        messages,
        modelCalls,
        toolCalls,
      });
    }
    messages.push(message);
    await events.emit({
      type: 'model_end',
      modelCall: modelCalls,
      stopReason: message.stopReason,
      toolCallCount: message.toolCalls.length,
    });
    if (control.stopStatus()) {
      return finishStopped();
    }

    if (message.stopReason === 'length') {
      return finish({
        status: 'truncated',
        messages,
        modelCalls,
        toolCalls,
      });
    }
    if (message.stopReason === 'stop') {
      if (!message.content.trim()) {
        return finish({
          status: 'emptyAnswer',
          messages,
          modelCalls,
          toolCalls,
        });
      }
      return finish({
        status: 'answered',
        answer: message,
        messages,
        modelCalls,
        toolCalls,
      });
    }
    // 保留旧规则：没有机会把结果交回模型的最后一批不执行。
    if (modelCalls === options.maxModelCalls) {
      return finish({
        status: 'callLimit',
        messages,
        modelCalls,
        toolCalls,
      });
    }
    try {
      // 具名传入通知、运行信号、时间刷新和预算申请；执行器不持有全局计数。
      const results = await executeToolBatch(message, registry, {
        signal: control.signal,
        notify: (event) =>
          events.emit({
            ...event,
            modelCall: modelCalls,
          }),
        checkStop: () => {
          control.stopStatus();
        },
        tryStartToolCall,
      });
      messages.push(...results);
    } catch (error) {
      if (error instanceof ToolBatchCancelled) {
        messages.push(...error.completedResults);
        return finishStopped();
      }
      // 工具额度不足保留此前项，不再请求模型或执行超额项。
      if (error instanceof ToolBatchLimit) {
        messages.push(...error.completedResults);
        return finish({
          status: 'toolLimit',
          messages,
          modelCalls,
          toolCalls,
        });
      }
      if (error instanceof ToolBatchError) {
        messages.push(...error.completedResults);
        return finish({
          status: 'failed',
          phase: 'tools',
          failure: error.failure,
          error,
          messages,
          modelCalls,
          toolCalls,
        });
      }
      return finish({
        status: 'failed',
        phase: 'tools',
        error,
        messages,
        modelCalls,
        toolCalls,
        failure: {
          code: 'tool_execution',
          message: '工具调度发生未知异常。',
        },
      });
    }
  }
  throw new Error('运行计数异常。');
}
